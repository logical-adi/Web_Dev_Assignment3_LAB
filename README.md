## Features
The application fulfills all requirements specified in the assessment task:
* **Semantic HTML Structure:** Developed using `<header>`, `<section>`, `<div>`, and `<button>` tags for improved accessibility and SEO.
* **Responsive Card Design:** A clean, card-style container with professional fonts, background colors, and hover effects.
* **Dynamic Quiz Logic:**
    * Stores 5+ multiple choice questions in a JavaScript Array of Objects.
    * Displays questions one at a time.
    * Prevents users from proceeding without selecting an option.
* **Score Calculation:** Automatically calculates and displays the final score upon completion.
* **Progress Tracking:** Includes a progress indicator (e.g., "Question 2 of 5").
* **Restart Functionality:** Allows users to reset the quiz without refreshing the page.
